# 🐍 SkillNexis Python Programming — Week 2

A collection of Python programming assignments and a mini project completed as part of the **SkillNexis Python Programming Course – Week 2**.

## 📚 Week 2 — Data Structures & File Handling

### Topics Covered

- Lists, Tuples, Sets and Dictionaries
- Reading and Writing Text Files
- CSV and JSON File Handling
- Exception Handling
- Data Storage and CRUD Operations

---

## 📝 Assignments

### 1. 📱 Contact Book using Dictionary

A dictionary-based contact book that allows users to:

- Add contacts
- Search contacts
- Update contacts
- Delete contacts
- Display all contacts

**File:** `Assignments/Assignment-1-Contact-Book/contact_book.py`

### 2. 📝 Word Counter from Text File

A Python program that reads a text file and counts:

- Number of words
- Number of lines
- Number of characters

**File:** `Assignments/Assignment-2-Word-Counter/word_counter.py`

### 3. 📄 JSON File Reader

A Python program that loads JSON data and displays it in a formatted, readable format.

**File:** `Assignments/Assignment-3-JSON-File-Reader/json_reader.py`

---

## 🧑‍🎓 Mini Project — Student Management System

A Python-based student management system that stores student information using a CSV file.

### Features

- ➕ Add student
- 👀 View students
- 🔍 Search student by roll number
- 🗑️ Delete student
- 💾 Store data permanently in CSV
- ⚠️ Handles invalid operations

### Student Data

The system stores:

- Roll Number
- Student Name
- Marks

**Python File:** `Mini-Project/Student-Management-System/student_management.py`

**CSV File:** `Mini-Project/Student-Management-System/students.csv`
